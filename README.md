# Инструкция по настройке Allure и запуску тестов

###  В проекте используются  аллюр шаги для подробного отчёта
###  Чтобы аллюр генерил файл с отчётом о тесте, нужно локально установить на пк аллюр. Если используестя дженкинс, то так же скачать плагин allure, по умолчанию его нет.
###  Тесты независимые. Нет влияния одного теста на другой.
###  Можем использовать параллельный запуск тестов, так как тесты независимые.
